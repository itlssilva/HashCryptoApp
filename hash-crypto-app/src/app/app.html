Hash Crypto App

Aplicação de criptografia e hashing desenvolvida para criação de hashes e criptografia de frases. Explore algoritmos de hash e técnicas de criptografia de forma prática e interativa.

Features

Criptografia

Algoritmos de criptografia simétrica e assimétrica para proteção de dados.

Hashing

Funções de hash como MD5, SHA-256 e bcrypt para verificação de integridade.

Segurança

Boas práticas de segurança aplicadas no desenvolvimento de software.

Sobre o Projeto

Este projeto foi desenvolvido para criação de Hash e Criptografia de frases. A aplicação demonstra conceitos fundamentais de criptografia e hashing utilizados na segurança da informação.
